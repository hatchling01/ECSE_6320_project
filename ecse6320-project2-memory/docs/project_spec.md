# Project specification

This repository implements ECSE 4320/6320 Project #2: Cache & Memory Performance Profiling. It characterizes dependent-load hierarchy latency, locality/pattern/stride, read/write mixes, concurrent loaded latency, working-set transitions, cache/TLB evidence and a misleading cache-reuse benchmark case on the audited AMD Windows host. The permanent safety and evidence constraints are in `AGENTS.md`; experiment matrices are in `config/experiments.json`.
